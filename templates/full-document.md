**用途**：最終輸出的完整文件格式，包含所有四個階段的成果  
**適用對象**：工程師、PM、AI Coding Tool

---

---

{{使用者原始需求描述，保持原文}}

## 使用說明

1. 將 `{{...}}` 替換為實際內容
2. 可依需求增減章節
3. 儲存為 `.md` 格式，可直接貼入 GitHub Issues、Notion、Confluence
4. 作為 AI Coding Tool prompt 時，建議附加以下說明：

```
以下是這個功能的完整規劃文件。請先閱讀全文，從「第一階段」的「T1.1」開始實作，
每完成一個任務告訴我，確認後再繼續下一個。若有任何不清楚的地方請先問我。
```
